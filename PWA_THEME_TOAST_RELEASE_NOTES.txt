THAKBO PWA + ACCESSIBLE THEME + SIDE TOAST UPDATE

Included:
- Web app manifest at public/manifest.webmanifest with standalone display and app icons.
- Install prompt shown on first visit unless already installed or dismissed for the session. Supports the browser install prompt where available and explains manual installation on iOS/Android otherwise.

IMPORTANT VERIFICATION STATUS:

- Full npm typecheck, lint, unit tests and production build must pass before deploying.
