THAKBO Phase 51 — বাংলা নির্দেশনা

এই আপডেটে রিপোর্টের বিবরণ ও Admin-এর internal note সংরক্ষণের আগে অপ্রয়োজনীয় control character সরিয়ে দেওয়া হয়। সাধারণ বাংলা, ইংরেজি, Unicode এবং নতুন লাইনের লেখা রাখা হয়।

আগের নিরাপত্তা:
- লগইন করা ব্যবহারকারীই রিপোর্ট করতে পারেন।
- নিজের লিস্টিং রিপোর্ট করা যায় না।
- একই লিস্টিংয়ে pending রিপোর্ট থাকলে একই ব্যবহারকারীর নতুন রিপোর্ট আটকে যায়।
- ২৪ ঘণ্টায় সর্বোচ্চ ১০টি রিপোর্টের সীমা আগের মতো আছে।
- Admin authorization আগের মতো আছে।

এটি source ZIP; GitHub push, Cloudflare deploy বা production DB পরিবর্তন করা হয়নি। পূর্ণ CI পরীক্ষা শেষ না হওয়া পর্যন্ত Production-এ deploy করবেন না।
