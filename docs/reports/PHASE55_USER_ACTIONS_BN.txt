THAKBO — Phase 55: Database Query ও Index Audit

এই ধাপে সোর্স কোডের ডেটাবেস Query এবং বিদ্যমান Index পর্যালোচনা করা হয়েছে। কোনো Production database-এ সংযোগ করা হয়নি এবং কোনো migration চালানো হয়নি।

মূল পর্যবেক্ষণ:
1. Listing, owner, location, image, facility এবং analytics-এর জন্য বেশ কিছু প্রয়োজনীয় Index আগে থেকেই আছে।
2. Keyword search-এ `%শব্দ%` ধরনের LIKE ব্যবহার হওয়ায় সাধারণ Index যোগ করলেই সেটি দ্রুত হবে—এমন নয়।
3. সঠিক Index বাছাইয়ের আগে বাস্তবসম্মত ডেটাসহ EXPLAIN QUERY PLAN ও latency পরীক্ষা করা দরকার।
4. তাই এই ধাপে অনুমান করে নতুন Index বা Database Migration যোগ করা হয়নি।

গুরুত্বপূর্ণ:
- এই ZIP এখনই Live সাইটে Deploy করবেন না।
- GitHub-এ Push বা Production Database-এ migration চালানোর প্রয়োজন নেই।
- পূর্ণ TypeScript, ESLint, Vitest এবং Production Build পরীক্ষা এখনও বাকি।
- বিস্তারিত ফলাফল docs/reports/phase-55-database-query-index-audit.md ফাইলে আছে।
